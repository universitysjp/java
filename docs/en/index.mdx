This module covers Java programming from the ground up, progressing through core language features to advanced object-oriented concepts.

## Getting started

- [Introduction](./introduction) — Java evolution, features, JVM/JRE/JDK, and basic syntax.
- [Data Types & Operators](./data-types) — Primitive and reference types, casting, and operators.

## Core language

- [Control Statements](./control-statements) — Selection, iteration, and jump statements.
- [Arrays](./arrays) — One- and two-dimensional arrays and common operations.
- [Strings](./strings) — String methods, immutability, and `StringBuilder`.

## Object-oriented programming

- [OOP Introduction](./oop-intro) — The motivation for OOP and its four pillars.
- [Classes & Objects](./classes-objects) — Constructors, instance methods, and `this`.
- [Encapsulation](./encapsulation) — Access modifiers, getters/setters, and static members.
- [Inheritance](./inheritance) — Inheritance types, `super`, and method overriding.
- [Polymorphism](./polymorphism) — Compile-time and runtime polymorphism.
- [Abstraction](./abstraction) — Abstract classes and interfaces.

## Exceptions and concurrency

- [Exceptions & Threading](./exceptions-threads) — Exception handling, thread lifecycle, and synchronization.

## Prerequisites

- A Java Development Kit (JDK) installed (version 8 or later).
- A text editor or IDE (e.g., IntelliJ IDEA, VS Code, Eclipse).

## How to Run Examples

Each topic has a corresponding example in the [`examples/`](https://github.com/University-Of-Sri-Jayewardenepura/Java/tree/main/examples) directory. Compile and run any example with:

```bash
javac ExampleName.java
java ExampleName
```
